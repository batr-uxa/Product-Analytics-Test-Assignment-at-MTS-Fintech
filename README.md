# Задача 1: АБ-тест баннера

## Условие
В МТС банке запустили аб-тест на странице, где можно оформить заявку на банковскую карту. 
В варианте А из 2574 клиентов, зашедших на страницу, на баннер нажали 350, в варианте Б из 2855 нажали 375. 
Какой вариант баннера предложить продакту и почему?

## Расчет конверсии
- Вариант А: 350 / 2574 = **13.60%**
- Вариант Б: 375 / 2855 = **13.13%**

На первый взгляд, вариант А лучше, так как конверсия выше на 0.47 п.п.

## Проверка статистической значимости
Чтобы понять, не является ли эта разница случайной, я провел Z-тест для пропорций.

**Гипотезы:**
- H0: Конверсии равны (p_A = p_B)
- H1: Конверсии различаются (p_A ≠ p_B)

**Результат Z-теста:**
- Z-статистика: **0.51**
- Критическое значение для 95% доверия: **1.96**

Так как |Z| = 0.51 < 1.96, мы **не отвергаем нулевую гипотезу**. Разница между вариантами статистически не значима.

## Вывод для продакта
Я бы **не рекомендовал** менять текущий баннер (или выбирать вариант Б) на основе этих данных, так как разница может быть случайной.
